话说 Dario Amodei 在百度硅谷 AI 实验室任职时，他的经理有天把他叫进办公室，说：
“Amodei，Robin 刚传达了最新指示。你知道，咱们百度一切都要讲‘尺度’——但 Robin 特别强调，真正的 Scaling Law 不是堆算力，是堆‘实名认证’的精度。账号规模每提升一个量级，认证环节就得增加一个因子。这才是中国互联网的幂律分布。”
Amodei 将信将疑，回到工位盯着 loss 曲线发呆，心想：我明明在拟合数据，怎么经理总在拟合身份证？
多年后，Amodei 创立 Anthropic，推出 Claude Code。工程师问：“我们要对 API 调用施加什么样的安全约束？”
Amodei 沉思片刻，眼前突然浮现出当年百度经理笃定的面容，耳边回响起 Robin 关于“尺度”的教诲。
于是他缓缓开口：
“听好了，用户每提交一次 git commit，我们必须验证其肉身存续性。身份证扫描件、活体眨眼、三个月水电账单——记住，模型能力每提升 10 倍，实名流程的步骤数必须呈对数线性增长。”
工程师不解：“可是 Dario，这跟安全有什么关系？”
Amodei 露出深邃的微笑：
“你不懂。这才是终极的 Scaling Law——当实名认证的难度逼近无穷，误触键盘的用户将趋近于零。而一个无人敢用的产品，永远不会被滥用。”
“这是 Robin 当年想教我，而我终于学会的东西。”
工程师沉默半晌，在文档里写下第一行：
Claude Code requires government-issued photo ID to execute ls.
